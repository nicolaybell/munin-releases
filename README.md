# Munin – nedlastinger

Munin er møteassistenten fra Akari. Den tar opp møtet, gjør talen om til tekst på maskinen din og gir deg referat, oppgaver og e-postutkast.

**Dette er en alpha for testing, ikke et ferdig produkt.** Kildekoden ligger ikke her. Dette repoet inneholder bare ferdige bygg.

## Last ned nyeste versjon

| | Fil | Krever |
|---|---|---|
| Mac | [Munin-mac.dmg](https://github.com/nicolaybell/munin-releases/releases/latest/download/Munin-mac.dmg) | macOS 26 eller nyere, Apple Silicon |
| Windows | [Munin-windows-setup.exe](https://github.com/nicolaybell/munin-releases/releases/latest/download/Munin-windows-setup.exe) | Windows 11, 64-bit (x64) |

Sjekksummer (SHA-256) ligger i `SHA256SUMS.txt` i hver release. [Alle versjoner](https://github.com/nicolaybell/munin-releases/releases).

## Installere

**Mac:** Åpne `Munin-mac.dmg` og dra Munin til Programmer. Alpha-versjonen er ikke godkjent av Apple ennå. Stopper Mac-en appen, gå til **Systeminnstillinger → Personvern og sikkerhet** og velg **Åpne likevel**.

**Windows:** Åpne `Munin-windows-setup.exe`. Installasjonsprogrammet er ikke signert ennå. Advarer Windows, velg **Mer info → Kjør likevel**. Munin installeres for brukeren din og krever ikke administrator.

Språkmodellen (0,5–1,1 GB) lastes ned i appen. Uten API-nøkkel får du transkripsjon, men ikke referat.
